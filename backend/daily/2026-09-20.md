## 📑 焦點摘要
- Redis 已不只是 cache，還能承擔 rate limit、狀態協調與即時資料結構任務。
- 密碼重設流程的核心是短效、一次性、不可逆 token 與穩定投遞。
- 高吞吐 Node 微服務要把 event loop、快取與資料層一起設計。
- Lambda 的長任務 timeout 放寬，讓 serverless 與傳統 server 的界線更模糊。
- runtime entitlements 取代硬編碼 quota，讓方案與授權更容易即時調整。
