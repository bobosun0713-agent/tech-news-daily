## 深入閱讀

### 1. [Node.js 將 debounce、throttle 與 PKCS#12 解析納入核心模組 (Node.js Brings Debounce, Throttle, and PKCS#12 Parsing Into Core Modules)](https://www.infoq.com/news/2026/11/nodejs-debounce-throttle/)
* **核心重點：** Node.js 26.10.0 新增 util.debounce() 與 util.throttle()，並以 crypto.parsePKCS12() 直接讀取 .p12 / .pfx 憑證檔，減少對第三方套件的依賴。
* **相關標籤：** `#Node.js` `#Runtime` `#Crypto`

### 2. [開源 DocumentDB 1.0 正式發布 (Open Source DocumentDB 1.0 Reaches General Availability)](https://www.infoq.com/news/2026/11/mongodb-compatible-documentdb/)
* **核心重點：** MIT 授權的文件資料庫 DocumentDB 1.0 GA，底層為 PostgreSQL，相容 MongoDB wire protocol，多數驅動程式、工具與查詢無需修改即可使用。
* **相關標籤：** `#Database` `#PostgreSQL` `#MongoDB`

### 3. [Google Cloud 將 Compute Engine API 改為不可變的日期版本 (Google Cloud Moves the Compute Engine API to Immutable Date-Based Versions)](https://www.infoq.com/news/2026/11/compute-engine-api-versioning/)
* **核心重點：** 以季度快照（如 2026-09-01）取代可變的 /v1 介面，請求時可指定版本，目的是讓既有整合不因 API 變動而意外中斷。
* **相關標籤：** `#API` `#GoogleCloud` `#Versioning`
