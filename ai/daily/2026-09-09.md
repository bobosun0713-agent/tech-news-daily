## 深入閱讀

### 1. [NeoHorse-1：透過 agentic post-training 與 routing harness 追求可遞迴自我改進 (NeoHorse-1: Towards Recursive Self-Improvement via Agentic Post-Training with Routing Harness)](https://huggingface.co/papers?date=2026-09-09)
* **核心重點：** 以路由訊號、分階段 curriculum 與 feedback loop，把 agent-native model 的學習循環做成可迭代系統。
* **相關標籤：** `#LLM` `#Agents` `#PostTraining`

### 2. [Omni Interaction Agent 技術報告：把多模態互動與 agent 能力合一 (Omni Interaction Agent Technical Report)](https://huggingface.co/papers?date=2026-09-09)
* **核心重點：** 用單一框架整合視訊、語音與文字的串流輸入，支援即時互動與 workflow 型 agent 場景。
* **相關標籤：** `#Multimodal` `#Realtime` `#AgenticAI`

### 3. [以 on-policy reverse distillation 追出弱到強的泛化 (Eliciting Weak-to-Strong Generalization with On-Policy Reverse Distillation)](https://huggingface.co/papers?date=2026-09-09)
* **核心重點：** 利用 verifier 與 on-policy policy gradient，讓較強模型從較弱監督中學出更穩定的泛化。
* **相關標籤：** `#Reasoning` `#RL` `#Verification`

### 4. [大型長上下文 RL 後訓練中的 speculative decoding draft co-training (Online Draft Co-Training for Speculative Decoding in Large-Scale, Long-Context RL Post-Training)](https://huggingface.co/papers?date=2026-09-09)
* **核心重點：** 透過 online co-training 提升 draft accuracy，讓 speculative decoding 在長上下文 RL 後訓練中更有效率。
* **相關標籤：** `#Inference` `#RL` `#SpeculativeDecoding`

### 5. [Agentic Visual Generation：從生成模型走向可控代理 (Agentic Visual Generation: From Generative Models to Agentic Control)](https://huggingface.co/papers?date=2026-09-09)
* **核心重點：** 把視覺生成視為可規劃、可選工具、可檢查與可修正的代理流程，而不是單次呼叫的輸出。
* **相關標籤：** `#Vision` `#Agents` `#GenerativeAI`
