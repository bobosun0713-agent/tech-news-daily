## 深入閱讀

### 1. [Holo4：面向通用 computer-use agent 的新系列模型 (Holo4: powering generalist computer-use agents)](https://huggingface.co/blog/Hcompany/holo4)
* **核心重點：** Holo4 以 GUI、code、MCP 與 API 多介面協作為設計核心，目標是把真實工作流程做完整。
* **相關標籤：** `#Agents` `#ComputerUse` `#Multimodal`

### 2. [OpenDecider：可校準決策模型，讓 typed decisions 更可控 (OpenDecider: Open, Calibrated Decision Models That Beat Laya and Jev on Typed-Decisions)](https://huggingface.co/blog/manjunathshiva/opendecider-beats-laya-and-jev)
* **核心重點：** 這類小模型專門做 bounded decision，重點不是長推理，而是穩定、可閾值化的機率輸出。
* **相關標籤：** `#DecisionModels` `#Calibration` `#Inference`

### 3. [NVIDIA 開放 Agent Safety Platform：把安全邊界搬到 runtime 與硬體層 (NVIDIA Launches Open Agent Safety Platform to Secure Agents From Testing to Deployment)](https://www.nvidia.com/en-us/solutions/ai/agent-safety/)
* **核心重點：** OpenShell + Sentry 把 agent 權限、可見範圍與異常封鎖，從提示詞治理提升到可執行邊界。
* **相關標籤：** `#AIAgents` `#Safety` `#Runtime`

### 4. [UK AISI 與 EvalEval 讓 benchmark 結果可重現 (How UK AISI and EvalEval Are Making Benchmark Results Reproducible)](https://huggingface.co/blog/evaleval-aisi)
* **核心重點：** 把評測設定、結果與上下文一起公開，讓研究者能重跑與比對，減少黑箱 benchmark。
* **相關標籤：** `#Evaluation` `#Reproducibility` `#Benchmarks`

### 5. [Saaras V4：覆蓋 22 種印度語言與全球英語的語音轉文字模型 (Sarvam AI Releases Saaras V4: A Speech-to-Text Model for All 22 Indian Languages and Global English)](https://www.marktechpost.com/2026/09/26/sarvam-ai-releases-saaras-v4-a-speech-to-text-model-for-all-22-indian-languages-and-global-english/)
