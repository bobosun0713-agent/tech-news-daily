## 深入閱讀

### 1. [DataFlex-RL：RLVR 資料政策評估平台 (DataFlex-RL: An Evaluation Platform for RLVR Data Policies)](https://huggingface.co/papers/2609.06107)
* **核心重點：** 用統一 GRPO 方案比較 rollout 與 reweighting 政策，檢驗資料策略是否真有穩定收益。
* **相關標籤：** `#LLM` `#Training` `#Evaluation`

### 2. [Benchmark Radar：AI benchmark 的活資料庫與搜尋引擎 (Benchmark Radar: A Living Database and Search Engine for AI Benchmarks and Evaluation)](https://huggingface.co/papers/2609.11115)
* **核心重點：** 將 benchmark 資訊做成可檢索資料庫，降低重複造輪子與評測迷航。
* **相關標籤：** `#Benchmark` `#Evaluation` `#Infra`

### 3. [COBRA-Skills：用 contextual bandit 優化技能演化 (COBRA-Skills: Contextual Bandit-Guided Evolution for Agent Skill Optimization)](https://huggingface.co/papers/2609.11682)
* **核心重點：** 讓 skill routing 與演化帶有 bandit 決策，朝更有效的 agent 技能選擇前進。
* **相關標籤：** `#Agents` `#Bandits` `#Optimization`

### 4. [TRACE：以證據排序提升 GUI agent admission 效率 (TRACE: Trajectory-robust Admission with Evidence Ordering for Efficient GUI Agents)](https://huggingface.co/papers/2609.10297)
* **核心重點：** 透過 evidence ordering 與軌跡穩健 admission，讓 GUI agent 更能過濾無效路徑。
* **相關標籤：** `#GUIAgents` `#Evaluation` `#Planning`

### 5. [突破視覺-動作捷徑：以 latent interface training 提升機器人基礎模型泛化 (Breaking the Vision-Action Shortcut: Latent Interface Training for Generalizable Robotics Foundation Models)](https://huggingface.co/papers/2609.12641)
* **核心重點：** 以 latent interface training 逼模型學到可泛化的視覺-動作對應，減少 shortcut learning。
* **相關標籤：** `#Robotics` `#FoundationModels` `#Generalization`
