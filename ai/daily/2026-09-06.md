## 深入閱讀

### 1. [Compile by Training：把自然語言規格編譯成本地神經函式 (Compile by Training: Turning Natural-Language Specifications into Local Neural Functions)](https://huggingface.co/papers?date=2026-09-06)
* **核心重點：** 把可描述的文字規格轉成可重用的神經函式，讓模型能力像軟體模組一樣能編譯、版本化與組合。
* **相關標籤：** `#LLM` `#Training` `#NeuralFunctions`

### 2. [Terminal-Universe：把 agent 軌跡重建成可執行終端環境 (Terminal-Universe: Turning Agent Trajectories into Scalable Terminal Environments)](https://huggingface.co/papers?date=2026-09-06)
* **核心重點：** 從既有軌跡反推出可執行環境，讓後訓練資料不只是一份示範，而是能回放與再驗證的任務場景。
* **相關標籤：** `#Agents` `#Environments` `#PostTraining`

### 3. [RealSWE：以真實需求導向的組合式評測檢驗 coding agents (RealSWE: A Compositional Evaluation of Coding Agents under Realistic User Requests)](https://huggingface.co/papers?date=2026-09-06)
* **核心重點：** 讓 coding agent 面對更接近真實工作請求的評測，避免只在單點 benchmark 上看起來很強。
* **相關標籤：** `#CodingAgents` `#Benchmark` `#Evaluation`

### 4. [DRACO：用動態 rubric 做長程 agent 訓練的精細 credit assignment (DRACO: Fine-Grained Credit Assignment with Dynamic Rubrics for Long-Horizon Agent Training)](https://huggingface.co/papers?date=2026-09-06)
* **核心重點：** 透過動態評分規則切分長任務回饋，讓 agent 在長鏈條訓練中更容易對齊每一步的貢獻。
* **相關標籤：** `#Agents` `#Training` `#LongHorizon`
