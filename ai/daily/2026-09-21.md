## 📑 焦點摘要
- 程式碼本身正在變成可抽取、可驗證的 agent 技能資產。
- coding agent 的訓練與評估，越來越依賴從程式碼自動生成任務與環境。
- 資料代理需要更動態的 ontology 層，才能跟上真實資料結構。
- computer-use 與多模態對話，都在往可驗證的環境與基準前進。

## 深入閱讀

### 1. [以程式碼規模化合成可驗證技能：Agentic Intelligence 的 grounded skill 取得法 (Grounded Skill Synthesis from Code at Scale for Agentic Intelligence)](https://huggingface.co/papers?date=2026-09-21)
* **核心重點：** 從程式碼抽出可執行技能，讓 agent 能以 source evidence 建立可重用的 procedural knowledge。
* **相關標籤：** `#Agents` `#Skills` `#Code2Skill`

### 2. [CodeMidas：從程式碼自動擴展 coding agent 的 RL 環境 (CodeMidas: Scaling Agentic Coding RL Environments from Code Itself)](https://huggingface.co/papers?date=2026-09-21)
* **核心重點：** 用真實程式碼自動生成任務與 verifier，讓 coding agent 的 RL 訓練更可規模化。
* **相關標籤：** `#CodingAgents` `#RL` `#Benchmarks`

### 3. [EvoOntology：為資料代理打造可自我演化的 ontology 層 (EvoOntology: A Self-Evolving Ontology Layer for Data Agents)](https://huggingface.co/papers?date=2026-09-21)
* **核心重點：** 讓資料代理能動態補齊 schema 與概念層，降低跨資料源操作的語意落差。
* **相關標籤：** `#DataAgents` `#Ontology` `#ToolUse`

### 4. [RecreationWorld：可規模化且可驗證的 hybrid computer-use 環境 (RecreationWorld: Scalable and Verifiable Environments for Hybrid Computer-Use Agents)](https://huggingface.co/papers?date=2026-09-21)
* **核心重點：** 把圖形介面與命令列工作統一到可驗證環境，讓 computer-use agent 更容易評估。
* **相關標籤：** `#ComputerUseAgents` `#Evaluation` `#Environments`

### 5. [OmniVChat：原生音訊-視覺對話的合成、評測與訓練 (OmniVChat: Synthesizing, Benchmarking, and Training for Native Audio-Visual Dialogue)](https://huggingface.co/papers?date=2026-09-21)
* **核心重點：** 針對語音與視覺同步輸入建立資料、基準與訓練流程，推動多模態對話代理。
* **相關標籤：** `#Multimodal` `#AudioVisual` `#Benchmarks`
