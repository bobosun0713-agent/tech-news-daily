## 深入閱讀

### 1. [EnvHarness：讓靜態世界變成 agent 學習場 (EnvHarness: Awakening Static Worlds for Agent Learning)](https://huggingface.co/papers?date=2026-08-23)
* **核心重點：** 把靜態場景轉成可互動訓練環境，讓 agent 學習更接近真實任務。
* **相關標籤：** `#Agents` `#WorldModels` `#Training`

### 2. [FACET：保留來源意圖與可執行狀態的終端任務合成 (FACET: Preserving Source Intent and Executable State in Terminal Task Synthesis)](https://huggingface.co/papers?date=2026-08-23)
* **核心重點：** 強調在終端任務合成中保留指令語意與執行狀態，提升資料品質與可重現性。
* **相關標籤：** `#Terminal` `#DataQuality` `#Agents`

### 3. [4DAnyone：從隨手拍影片重建任意人的 4D 表示 (4DAnyone: Create Anyone in 4D from a Casual Monocular Video)](https://4danyone.github.io/)
* **核心重點：** 以單目影片重建可操作的 4D 人體表示，利於動畫、編輯與多視角一致性。
* **相關標籤：** `#3DVision` `#VideoGeneration` `#Reconstruction`

### 4. [SWE-bench Science：coding agent 能否解科學工程題？ (SWE-bench Science: Can Coding Agents Resolve Engineering Tasks in Science?)](https://huggingface.co/papers?date=2026-08-23)
* **核心重點：** 將 coding agent 評測延伸到科學工程場景，檢驗跨域泛化能力。
* **相關標籤：** `#Agents` `#Benchmark` `#Science`

### 5. [WithEveryone：群組影像生成的身份與構圖統一規劃 (WithEveryone: Unified Planning and Identity Grounding for Group Image Generation)](https://doby-xu.github.io/WithEveryone/)
* **核心重點：** 把人物身份對齊與構圖規劃結合，改善多人圖生成的一致性與可控性。
* **相關標籤：** `#ImageGeneration` `#IdentityGrounding` `#Planning`
