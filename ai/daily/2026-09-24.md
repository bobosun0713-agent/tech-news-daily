## 深入閱讀

### 1. [Just-In-Time Memory：為 LLM Agent 動態整理任務記憶 (Just-In-Time Memory: Learning to Curate Task-Adaptive Memory for LLM Agents)](https://huggingface.co/papers?date=2026-09-24)
* **核心重點：** 把 memory 變成任務中可動態策展的資源，讓 agent 不再只能用靜態記憶庫。
* **相關標籤：** `#Memory` `#Agents` `#LLM`

### 2. [Schrödinger 的程式庫：LLM 是真的學會 SWE-bench，還是背過了？ (Schrödinger's Code Repository: Have LLMs Learned SWE-bench or Memorized It?)](https://huggingface.co/papers?date=2026-09-24)
* **核心重點：** 研究 coding benchmark 是否遭資料洩漏污染，提醒我們評估要先分清楚學習與記憶。
* **相關標籤：** `#Eval` `#CodingAgents` `#Benchmark`

### 3. [Spatial-Interactor：透過與可觀察世界互動學空間推理 (Spatial-Interactor: Learning Spatial Reasoning through Interaction with the Observable Physical World)](https://huggingface.co/papers?date=2026-09-24)
* **核心重點：** 讓 VLM 從靜態理解走向互動式空間推理，強調環境回饋對推論的重要性。
* **相關標籤：** `#SpatialReasoning` `#VLM` `#Interaction`

### 4. [HappyWorld-Bench：世界模型的互動式一致性評測 (HappyWorld-Bench)](https://huggingface.co/papers?date=2026-09-24)
* **核心重點：** 世界模型不只要會生成，還要在互動、修改與長時序探索下維持一致性。
* **相關標籤：** `#WorldModels` `#Benchmarks` `#Consistency`

### 5. [影片生成也需要記憶：The Past Frames the Future (The Past Frames the Future: Memory for Autoregressive Video Generation)](https://huggingface.co/papers?date=2026-09-24)
* **核心重點：** 把過去影格納入自回歸生成記憶，讓長影片的延續性與事件順序更穩。
* **相關標籤：** `#VideoGeneration` `#Memory` `#Autoregressive`
