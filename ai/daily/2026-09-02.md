## 深入閱讀

### 1. [Harness-of-Harness：多日自治軟體開發的持續改進框架 (Harness-of-Harness: Multi-Day Autonomous Software Development with Continual Improvement)](https://flesymeb.github.io/HarnessOfHarness/)
* **核心重點：** 在既有 coding agent harness 上套迭代式 planning-coding-testing 迴圈，讓自治開發可持續提升。
* **相關標籤：** `#Agents` `#SoftwareEngineering` `#AutonomousDev`

### 2. [Agents in the Large：面向長期服務的感知中心代理架構 (Agents in the Large: Perception-Centered Architecture for Persistent Agents)](https://huggingface.co/papers/2608.30478)
* **核心重點：** 提出持續型代理架構，把感知與控制做成長壽命服務，支援長期演化與任務切換。
* **相關標籤：** `#Agents` `#Architecture` `#PersistentAgents`

### 3. [Control-Data Flow Separation：穩定的多代理 Prompt 最佳化 (Control-Data Flow Separation: Stable Prompt Optimization in Multi-Agent LLMs)](https://github.com/yuntian-group/cdsep)
* **核心重點：** 將執行協議與可優化語言分離，避免 prompt tuning 搞壞路由與格式規則。
* **相關標籤：** `#MultiAgent` `#PromptOptimization` `#LLM`

### 4. [E-Commerce Bench：長週期自治商務操作評測 (E-Commerce Bench: Evaluating LLM Agents on Long-Horizon Autonomous Business Operation)](https://ecbench.github.io/)
* **核心重點：** 用一年期電商經營場景評估 LLM agent，觀察談判、庫存、訂單與資金流的長程表現。
* **相關標籤：** `#Benchmark` `#Agents` `#LongHorizon`
