## 深入閱讀

### 1. [TokenRouter：高效率的 token-level LLM routing 服務系統 (TokenRouter: Efficient Serving System for Token-Level LLM Routing)](https://huggingface.co/papers/2610.12242)
* **核心重點：** 以 request 觀點和 subserver 延遲批次排程處理路由，讓 token-level routing 更適合實際 serving 場景。
* **相關標籤：** `#LLMServing` `#Routing` `#Inference`

### 2. [SparseDecoding：解碼感知的剪枝框架，讓推論更省 (SparseDecoding: Decoding-Aware Pruning for Accurate and Efficient LLM Inference)](https://huggingface.co/papers/2610.12327)
* **核心重點：** 將 pruning 對齊 decoding 階段的實際激活，目標是提高準確率同時降低 wall-clock 成本。
* **相關標籤：** `#Pruning` `#LLMInference` `#Efficiency`

### 3. [MiMo-V2.6：以強化學習擴展自我改善 (MiMo-V2.6: Scaling Reinforcement Learning Towards Self-Improvement)](https://huggingface.co/papers/2610.11959)
* **核心重點：** Xiaomi MiMo 系列把 RL 算力往 self-improvement 推進，代表 omni-modal 基礎模型的訓練路線持續進化。
* **相關標籤：** `#ReinforcementLearning` `#FoundationModels` `#SelfImprovement`

### 4. [TestPrism：超越單一 reference 的測試評估 (TestPrism: Rethinking Test Evaluation Beyond a Single Reference)](https://huggingface.co/papers/2610.12289)
* **核心重點：** 用多候選與 Joint Success Function 評估 test quality，避免只對照單一 reference 而高估測試表現。
* **相關標籤：** `#CodeAgents` `#Evaluation` `#Testing`
