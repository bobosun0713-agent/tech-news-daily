## 深入閱讀

### 1. [科學研究代理 ScienceBuddy：讓互動式科學工作流能持續自我改進 (ScienceBuddy: Recursive-in-Recursive Self-Improvement for Interactive Scientific Agents)](https://huggingface.co/papers/2609.17523)
* **核心重點：** 以 harness evolution + model RL 讓科學代理從回饋與證據中持續進化。
* **相關標籤：** `#Agents` `#SelfImprovement` `#ScientificAI`

### 2. [從凍結 LLM 讀出原生技能路由訊號 (The Router Within: Eliciting Native Skill Routing from a Frozen LLM)](https://huggingface.co/papers/2609.15982)
* **核心重點：** 以線性映射從 frozen LLM 的中間層讀出 skill routing，不必把整個技能庫塞進 context。
* **相關標籤：** `#AgentRouting` `#Skills` `#Efficiency`

### 3. [用 Decoy Direction Optimization 擋住 LLM ablation 攻擊 (Decoy Direction Optimization: A Post-Hoc Defense Against LLM Abliteration)](https://huggingface.co/papers/2609.16204)
* **核心重點：** 以高幅度 decoy signal 迷惑拒答方向萃取，降低安全機制被移除的風險。
* **相關標籤：** `#Safety` `#ModelEditing` `#Defenses`

### 4. [漂移預算下的微調：控制模型改變的方向而不只是幅度 (Drift-Constrained Optimization: Only Direction Matters in Fine-Tuning Instruct Models)](https://huggingface.co/papers/2609.13680)
* **核心重點：** 把 fine-tuning 視為方向選擇問題，在可控 drift budget 內提升目標能力。
* **相關標籤：** `#FineTuning` `#Optimization` `#LLM`

### 5. [多模態自回歸世界動作模型：ModAR 先去噪再決策 (Modality-Autoregressive World-Action Models)](https://huggingface.co/papers/2609.17524)
* **核心重點：** 先生成點軌跡、深度與特徵，再預測動作，提升 embodied task 的效率與成功率。
* **相關標籤：** `#WorldModels` `#Multimodal` `#Robotics`
