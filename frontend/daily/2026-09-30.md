### 1. [Tailwind Labs 加入 Shopify：Tailwind 進入 Shopify 時代 (Tailwind Labs is joining Shopify)](https://tailwindcss.com/blog/tailwind-is-joining-shopify)
* **核心重點：** Tailwind 團隊併入 Shopify，代表設計系統、元件模板與產品工具鏈會更緊密地和 Shopify 的前端基礎設施協作。
* **相關標籤：** `#TailwindCSS` `#Shopify` `#FrontendEcosystem`

### 2. [Tailwind CSS v4 遷移指南：Breaking changes 與 @theme 設定 (TailwindCSS v4 Migration Guide: Breaking Changes & the @theme Config)](https://dev.to/umesh_malik/tailwindcss-v4-migration-guide-what-changed-and-how-to-upgrade-525g)
* **核心重點：** v4 將設定搬進 CSS 的 `@theme`，並把 Tailwind 推成 Vite plugin；升級時要先處理 config 與 class 變更。
* **相關標籤：** `#TailwindCSS` `#Migration` `#CSSFirst`

### 3. [Vite 8 + React 19 的 Tailwind v4 安裝錯誤修法 (Tailwind CSS v4 Install Error in Vite 8 (React 19) – Complete Fix)](https://dev.to/ismailjosim/tailwind-css-v4-install-error-in-vite-8-react-19-complete-fix-4g1l)
* **核心重點：** `@tailwindcss/vite` 的 peer dependency 邊界會在 Vite 8 觸發 `ERESOLVE`，實務上常用 overrides 或 `--legacy-peer-deps` 解掉。
* **相關標籤：** `#Vite` `#React` `#TailwindCSS`

### 4. [用 Vite + React + TypeScript + Tailwind v4 + shadcn/ui 組乾淨骨架 (How to install shadcn/ui with Vite, React, TypeScript, and Tailwind CSS v4 using pnpm.)](https://dev.to/ignatium/setting-up-shadcnui-with-vite-react-typescript-and-tailwind-css-v4-using-pnpm-274g)
