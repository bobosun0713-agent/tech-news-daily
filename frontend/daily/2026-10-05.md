## 深入閱讀

### 1. [Tailwind CSS v4.3：捲軸、色盤與 `@variant` 再進化 (Tailwind CSS v4.3: Scrollbars, new colors, and more)](https://tailwindcss.com/blog/tailwindcss-v4-3)
* **核心重點：** v4.3 加入 scrollbar、`@container-size`、`zoom-*`、`tab-*` 與 stacked/compound `@variant`，v4.2 也補進新色盤與 webpack 插件。
* **相關標籤：** `#TailwindCSS` `#CSS` `#Frontend`

### 2. [Oxc/Oxlint 支援 React Compiler：Vite 8 的自動 memo 化更快更完整 (React Compiler Support)](https://daily.dev/posts/react-compiler-support-o4lppwosx)
* **核心重點：** Oxlint 新增 22 條 React Compiler 規則，Oxc Transform 與 `@vitejs/plugin-react` v6.1.0 讓 Vite 8 的自動 memo 化更快更順。
* **相關標籤：** `#React` `#Vite` `#Oxlint`

### 3. [StyleX 深入解析：用編譯期 CSS-in-JS 讓 AI 產碼更可控 (A deep dive into StyleX)](https://daily.dev/posts/a-deep-dive-into-stylex-kzuvty0mp)
* **核心重點：** StyleX 以 `stylex.create()` 與 `stylex.props()` 在建置期產生 atomic CSS，兼顧 React/Vite 整合、可維護性與 AI 生成程式碼的一致性。
* **相關標籤：** `#StyleX` `#React` `#CSSinJS`
