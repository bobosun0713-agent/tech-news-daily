## 📑 焦點摘要
- 今天的前端重點集中在首屏效能與互動元件成本，特別是 widget、hero 效果與載入動畫不要拖垮 Core Web Vitals。
- Next.js 與 Base UI 的案例都在強調同一件事：把 UI 組裝往更 server-first、可維護、低耦合的方向推進。
- 視覺效果仍然重要，但真正的競爭力是用更小的腳本與更清楚的邊界，保住速度與一致性。
